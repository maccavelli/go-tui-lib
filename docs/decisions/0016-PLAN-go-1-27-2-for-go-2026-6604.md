### Step 1: records

* This pair.
* Its two rows in `docs/README.md`.
* 0014-PLAN-component-native-forms' D8, which names this record.

**Done when** the owner approves this PLAN. The commit holds the records
only, under the bootstrap exception.

### Step 2: both hosts

* **This host:** `go env -w GOTOOLCHAIN=go1.27.2`. Then:
  * `go version` must report `go1.27.2 darwin/arm64`. The first run
    fetches the toolchain through `GOPROXY`, checked against `GOSUMDB`;
  * `go env GOTOOLCHAIN` must say `go1.27.2`.
* **The Windows test host:** the same command, over the same SSH route
  the Windows runs use. `go version` must report `go1.27.2
  windows/amd64`.
* **Before Step 3,** with `go.mod` still at 1.27.1, `GOWORK=off
  govulncheck ./...` on this host must report no called vulnerability.
  govulncheck reads the standard library of the toolchain that runs it.
  So this proves the toolchain move alone clears the advisory.

**Done when** both hosts report go1.27.2 and the vuln check passes.
Nothing is committed.

### Step 3: the floor and its descriptions

* **`go.mod` and `go.work`:** `go 1.27.1` becomes `go 1.27.2`, through
  `go mod edit -go=1.27.2` and `go work edit -go=1.27.2`. `go mod tidy
  -diff` must stay clean, and `go.sum` must not change.
* **`AGENTS.md`:**
  * the intro: "Requires Go 1.27.2.";
  * API convention 11: "today 1.27.2", citing this record.
* **`README.md`:** "**Go 1.27.2** is required."
* **`docs/architecture.md`:** "**Go 1.27.2**, with no `toolchain` line."
* **Checks:**
  * `make vuln`: no called vulnerability;
  * `make release-check`: clean, with the same file count as before;
  * `make lint`, and with `GOWORK=off`, `-race`, `-shuffle=on -count=2`
    and `LC_ALL=C`, and workspace mode;
  * `scripts/go-modules.sh --check`; `make apicheck`; `make examples`;
  * the Windows test host: `make pre-add-check` and `make vuln`;
  * markdownlint, the link check, and the identifier scan of the diff.

  The W2 files in the tree are present for these runs, as they are for
  every gate. The record says so.
* **The commit** stages exactly these five paths and this PLAN.
